================================================================================
DEPLOYMENT GUIDE - Dual Port Support (Port 80 & 25345)
================================================================================

QUICK START (5 minutes):

1. SSH into VPS:
   ssh root@ctrader.emmanuelshekinah.co.za

2. Run deployment script:
   cd /root
   bash deploy-with-nginx-fix.sh

3. Test endpoints:
   
   Port 80 (via Nginx):
   curl http://ctrader.emmanuelshekinah.co.za/health
   curl -X POST http://ctrader.emmanuelshekinah.co.za/webhook \
     -H "Content-Type: application/json" \
     -d '{"symbol":"XAUUSD","action":"SELL","price":"3345.12","time":"2026-05-27T10:00:00Z"}'
   
   Port 25345 (Direct):
   curl http://ctrader.emmanuelshekinah.co.za:25345/health
   curl -X POST http://ctrader.emmanuelshekinah.co.za:25345/webhook \
     -H "Content-Type: application/json" \
     -d '{"symbol":"XAUUSD","action":"SELL","price":"3345.12","time":"2026-05-27T10:00:00Z"}'

4. Configure cBot:
   Option A: Server=ctrader.emmanuelshekinah.co.za, Port=80, HTTPS=false
   Option B: Server=ctrader.emmanuelshekinah.co.za, Port=25345, HTTPS=false

================================================================================
ENDPOINTS AVAILABLE ON BOTH PORTS
================================================================================

GET /
  Returns API info
  Port 80:   http://ctrader.emmanuelshekinah.co.za/
  Port 25345: http://ctrader.emmanuelshekinah.co.za:25345/

GET /health
  Returns health status
  Port 80:   http://ctrader.emmanuelshekinah.co.za/health
  Port 25345: http://ctrader.emmanuelshekinah.co.za:25345/health

GET /signal
  Returns latest stored signal
  Port 80:   http://ctrader.emmanuelshekinah.co.za/signal
  Port 25345: http://ctrader.emmanuelshekinah.co.za:25345/signal

POST /webhook
  Receive TradingView alerts
  Port 80:   http://ctrader.emmanuelshekinah.co.za/webhook
  Port 25345: http://ctrader.emmanuelshekinah.co.za:25345/webhook

================================================================================
WHAT THE SCRIPT DOES
================================================================================

1. Stops conflicting Nginx instances
2. Creates fixed Nginx configuration
3. Enables the site
4. Tests Nginx configuration
5. Starts Nginx
6. Verifies both ports are listening
7. Tests all endpoints on both ports

================================================================================
VERIFICATION
================================================================================

Check Nginx is running:
  sudo systemctl status nginx

Check both ports are listening:
  sudo netstat -tlnp | grep -E ":80|:25345"

Check Nginx config:
  sudo nginx -t

View Nginx error log:
  tail -f /var/log/nginx/error.log

================================================================================
TROUBLESHOOTING
================================================================================

Port 80 returns 404:
  sudo systemctl restart nginx
  sudo nginx -t
  tail -f /var/log/nginx/error.log

Port 25345 not responding:
  docker ps | grep tradingview
  curl http://localhost:25345/health

Multiple Nginx processes:
  sudo systemctl stop nginx
  killall nginx 2>/dev/null || true
  sudo systemctl start nginx

================================================================================
CBOT CONFIGURATION
================================================================================

Use either port in your cBot settings:

Option A (Port 80 via Nginx):
  Server IP/Domain: ctrader.emmanuelshekinah.co.za
  Server Port: 80
  Use HTTPS: false

Option B (Port 25345 Direct):
  Server IP/Domain: ctrader.emmanuelshekinah.co.za
  Server Port: 25345
  Use HTTPS: false

Both work identically!

✓ Deployment script runs without errors
