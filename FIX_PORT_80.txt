FIX PORT 80 - Quick Solution
================================================================================

PROBLEM:
  Port 80 returns 404 on /webhook
  Port 25345 works fine

CAUSE:
  Dokploy is managing Nginx and overriding the configuration

SOLUTION:
  Run the force fix script that bypasses Dokploy

================================================================================
ONE-COMMAND FIX
================================================================================

ssh root@ctrader.emmanuelshekinah.co.za
cd /root
bash fix-port-80.sh

That's it! The script will:
  1. Stop Nginx
  2. Backup current config
  3. Create fixed Nginx configuration
  4. Enable the site
  5. Test configuration
  6. Start Nginx
  7. Test all endpoints on both ports

================================================================================
WHAT THE FIX DOES
================================================================================

The fix-port-80.sh script:

1. Stops Nginx to prevent conflicts
2. Backs up the current configuration
3. Creates a new Nginx configuration that:
   - Listens on port 80
   - Proxies all requests to port 25345
   - Forwards the Content-Type header (critical for POST)
   - Handles all HTTP methods (GET, POST, PUT, DELETE)
   - Includes proper buffering and timeouts
4. Enables the site
5. Tests the configuration
6. Starts Nginx
7. Verifies both ports are listening
8. Tests all endpoints

================================================================================
TROUBLESHOOTING
================================================================================

If port 80 still doesn't work after running the script:

1. Check Nginx is running:
   sudo systemctl status nginx

2. Check both ports are listening:
   sudo netstat -tlnp | grep -E ":80|:25345"

3. Check Nginx configuration:
   sudo nginx -t

4. Check error log:
   tail -f /var/log/nginx/error.log

5. Restart Nginx:
   sudo systemctl restart nginx

6. Run diagnostic script:
   bash diagnose-nginx.sh
