================================================================================
METHODS OVERVIEW
================================================================================

OnStart()
├── Purpose: Initialize cBot
├── Called: Once when cBot starts
└── Responsibilities:
    ├── Log startup message
    ├── Initialize HTTP client
    ├── Initialize signal tracking
    ├── Setup polling timer
    └── Start polling

PollWebhookServer()
├── Purpose: Poll webhook server for signals
├── Called: Every PollIntervalMs milliseconds
└── Responsibilities:
    ├── Prevent concurrent polling
    ├── Build webhook URL
    ├── Fetch signal
    ├── Check for duplicates
    └── Execute trade if new signal

FetchSignalAsync(string url)
├── Purpose: Fetch signal from webhook server
├── Returns: WebhookSignal or null
└── Responsibilities:
    ├── Send GET request
    ├── Check response status
    ├── Read response content
    ├── Deserialize JSON
    └── Handle errors

IsDuplicateSignal(WebhookSignal signal)
├── Purpose: Check if signal is duplicate
├── Returns: bool (true if duplicate)
└── Logic:
    ├── Compare symbol
    ├── Compare action
    ├── Compare price
    └── Return true if all match

ExecuteTradeAsync(WebhookSignal signal)
├── Purpose: Execute trade based on signal
├── Responsibilities:
    ├── Validate signal
    ├── Get symbol from cTrader
    ├── Determine trade direction
    ├── Calculate stop loss/take profit
    ├── Execute trade
    └── Log result

Log(string message)
├── Purpose: Log message to cTrader
├── Format: [YYYY-MM-DD HH:MM:SS.fff] message
└── Configurable: Enable/disable logging

OnStop()
├── Purpose: Clean up resources
├── Called: Once when cBot stops
└── Responsibilities:
    ├── Mark as not running
    ├── Stop polling timer
    ├── Dispose HTTP client
    └── Log stop message

================================================================================
TESTING PROCEDURES
================================================================================

1. Test Server Connection
   Command: curl http://SERVER_IP:25345/health
   Expected: HTTP 200 with health status

2. Send Test Signal
   Command: curl -X POST http://SERVER_IP:25345/webhook \
            -H "Content-Type: application/json" \
            -d '{"symbol":"EURUSD","action":"BUY","price":"1.0850",...}'
   Expected: Signal received and logged

3. Monitor Logs
   Location: cTrader Output Panel
   Expected: Trade execution logs

4. Test Duplicate Detection
   Action: Send same signal twice
   Expected: First trade executes, second is ignored

5. Test Error Handling
   Action: Send invalid symbol
   Expected: Error logged, no trade executed

================================================================================
TROUBLESHOOTING
================================================================================

Compilation Error
├── Error: JsonProperty not found
├── Solution: Add using Newtonstein.Json;
└── Recompile

Connection Refused
├── Error: Unable to connect to server
├── Solution: Check server IP, port, firewall
└── Test: curl http://SERVER_IP:25345/health

No Signals Received
├── Error: cBot running but no signals
├── Solution: Verify server is running and accessible
└── Test: Send test signal manually

Trades Not Executing
├── Error: Signals received but no trades
├── Solution: Check account balance, symbol availability
└── Verify: Volume limits, permissions

High CPU Usage
├── Error: cBot consuming excessive CPU
├── Solution: Increase poll interval
└── Disable: Logging if not needed
